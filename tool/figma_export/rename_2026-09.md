# Section rename — 2026-09-08

The design renamed the three wellness sections. Applied to every user-facing
label in the app.

| Was | Now |
|---|---|
| Meditation | Pilates & Core |
| Balance | Stretch & Restore |
| Schedule / Schedule Session | Book a licensed Expert |

Ids, route paths, asset paths, enum names and repository query strings are
unchanged — only display strings moved, so nothing in the data layer had to be
migrated.

## Where the labels live

`LibrarySection.title`, `ExploreDestination.label`, `WellnessTrack.label`,
`SessionOffering.title`, `CheckinKind.title`, the Profile stat labels, the
`MediaItem.tag` default plus the mock repository's tagged items, `Coach`
expertise, and the Schedule/booking screen headers.

Everything in `DailyController` — `startLabel`, `emptyState`, `reminderTitle`,
`reminderBlurb` — derives from `CheckinKind.title`, so those renamed
themselves.

## Layout fallout

The new names are much longer than the words the frames were drawn with. One
real break: the Home "Explore" tile ellipsised "Book a licensed Expert" to
"Book a licensed Ex...". The tile label is now two lines. Everything else —
the Profile stats card, the daily-habit screens, the library header — already
wrapped or had the room.

## Left alone deliberately

These use the words as ordinary English, not as the name of a section:

- `LibrarySection.balance` promo body — "Schedule a wellness session with a
  coach today" (verb).
- `matched_view.dart` — "Schedule for later" (verb).
- `schedule_screen.dart` heading — "Schedule live sessions with experts"
  (verb).

Two more are unresolved rather than decided, and want a look at the frames:

- `IntroSlide` — onboarding slide 2 is titled "Guided Meditation" and its body
  says "guided meditation sessions". This is design copy verified against the
  old file; changing the title alone would leave the body stale, and changing
  both would be inventing copy. Re-read the onboarding frames before touching
  it (page 124:2, ids 176:23625 and 176:23645).
- `mock_content_repository` item 14 is *titled* "Balance" with the subtitle
  "Vinyasa flow" — a content title in the same shape as "Facing Fear", not a
  section label. Left as content.

## Note on the design's own consistency

The rename is partial in Figma. The library and filter frames use the new
names; the KYC, Profile daily/reminder and Recommendation frames still say
"Meditation" and "Balance". The app is now uniformly on the new names, per an
explicit call: "the renaming should be every user-facing instance".
